Flow JS-Native Bridge postMessage Payload Tester

PoC untuk mengirim payload arbitrer ke bridge JS-native (via window.postMessage) dan, opsional, mengirim payload besar via ethereum.request untuk mereplikasi error "Error invoking postMessage: Java exception was raised during method invocation".

Catatan: 1024 KB ≈ 1 MB. Sesuaikan ukuran payload kalau ingin menghindari freeze browser.
